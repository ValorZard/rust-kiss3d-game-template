# Template for game jams using Kiss3D

[you can play the web version of this template here](https://valorzard.itch.io/rust-kiss3d-game-template)

## to run native client
```bash
cargo run
```

## to run wasm client
```bash
trunk serve
```

## to export to itch.io
```bash
# note: you should read this script since you will need to edit certain parameters depending on your project's name.
./upload_game.sh
```
